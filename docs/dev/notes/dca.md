# DCA 定投策略（领域知识 + 测试用例）

> DCA模型暂未使用，后期再改改 ， 支持自定义周期，而不是固定的一周。  天数+金额

### 信号判断逻辑（核心）

**输入：** 近 20 天收盘价数组 `prices[]`，今天是否 `>= deadlineDay`

|Strategy|买入条件|兜底逻辑|等待条件|
|---|---|---|---|
|FIXED|永远买|—|—|
|MA5|`prices[-1] < avg(prices[-5:])`|deadline 到了强制买|高于 MA5 且未到截止日|
|RSI|RSI(14) < 40|deadline 到了强制买|RSI ≥ 40 且未到截止日|
|COMBINED|MA5↓ **且** RSI<45 → 全仓；MA5↓ **或** RSI<45 → 半仓|deadline 到了全仓强制买|两者都不满足且未到截止日|

**RSI 计算：** 标准 RSI(14)，数据不足 15 条时返回 50（中性）。

## 测试数据说明

**固定测试日期：** Wednesday 2026-06-17（`getDay()=3`），用于控制 deadline 判断：

- `deadlineDay=5` → 3 < 5 → **未到截止日**
- `deadlineDay=3` → 3 ≥ 3 → **截止日已到**
